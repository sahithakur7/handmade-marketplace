# Artisan Market - Handmade Artist Marketplace

A modern, beautiful marketplace for handmade artists and creators to showcase and sell their products. Built with React and Tailwind CSS.

## 🎨 Features

### For Customers
- **Browse Products** - Discover handmade items with beautiful product listings
- **Artist Profiles** - Learn about artists and their stories
- **Shopping Cart** - Add items and manage purchases
- **Product Reviews** - Read and write reviews
- **Wishlist** - Save favorite items
- **Responsive Design** - Perfect on mobile, tablet, and desktop

### For Artists
- **Artist Dashboard** - Manage products and track sales
- **Product Upload** - List new handmade items
- **Sales Analytics** - Track views, sales, and revenue
- **Order Management** - Manage customer orders

## 🛠️ Tech Stack

- **Frontend**: React 18 + React Router
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Fonts**: Playfair Display + Inter

## 🚀 Getting Started

1. Install dependencies: `npm install`
2. Start dev server: `npm start`
3. Open http://localhost:3000
